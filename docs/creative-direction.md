# Shivani Arya — Creative Direction

## Core Concept

A Woman in Many Frames.

The website presents Shivani Arya not simply as a portfolio owner,
but as a creative personality capable of inhabiting multiple worlds.

She is presented across four creative identities:

- Actress
- Model
- Creator
- Woman

## Creative Influences

The visual language combines:

- Indian cinematic romance
- Dreamy Bollywood aesthetics
- Contemporary fashion editorial
- Experimental art
- Luxury magazine design
- Surreal imagery
- Minimal modern web design

Bollywood inspiration includes the emotional and dreamy visual
language associated with classic Yash Raj Films and films such as
Mohabbatein and Kabhi Khushi Kabhie Gham.

The website must be inspired by the feeling of these references,
not directly imitate copyrighted movie artwork or branding.

## Personality

The website should communicate:

- Elegant
- Mysterious
- Bold
- Artistic
- Rebellious
- Cinematic

## Primary Visual Idea

The visitor should feel as though they are entering Shivani's
creative world rather than browsing a conventional resume website.

The experience should move through:

Mystery
→ Curiosity
→ Beauty
→ Personality
→ Transformation
→ Work
→ Ambition
→ Contact

## Visual Language

Primary visual characteristics:

- Editorial photography
- Large expressive typography
- Layered compositions
- Organic image masks
- Film-inspired transitions
- Subtle grain/textures
- Elegant serif typography
- Clean modern sans-serif typography
- Controlled asymmetry
- Strong negative space

## Core Statement

A woman in many frames.

The design should communicate transformation,
